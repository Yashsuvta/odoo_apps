Always Debug Mode

This module enables debug mode for selected users automatically, without needing to manually add ?debug=1 in the URL.

  • Adds a checkbox "Always Enable Debug Mode" on the user form.
  • When enabled, the user session always runs in debug mode (developer tools, technical features, etc.).
  • Note: The URL will not show ?debug=1, but debug mode is still active in the backend.

Best for: Developers, testers, or admins who work constantly in debug mode.
