Always Debug Mode
=================

Technical Name: always_debug_mode
Summary: Automatically enables debug mode (?debug=1) for selected users on login.
Author: Sebin Thomas
Version: 16.0.1.0.0

Key Features:
Adds a checkbox "Always Enable Debug Mode" in the user form.

Automatically appends ?debug=1 to URLs for users with this flag.

Helps developers and testers save time without manually toggling debug mode.
