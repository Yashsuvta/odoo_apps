Contact Field Validation

Real-time frontend and backend validation for phone and email fields in Odoo 17.

Why This Module?

In standard Odoo, users can enter invalid phone numbers and email addresses which may cause incorrect customer and employee data.

This module adds real-time frontend validation and backend email validation to improve data quality across Odoo forms.

Main Features

Phone Validation

Blocks alphabets and invalid characters while typing in phone fields.

Email Validation

Prevents invalid email addresses from being saved in Odoo.

Dynamic Detection

Automatically detects fields inside notebook pages and dialogs.

Paste Cleaning

Invalid characters are automatically removed from pasted values.

Supported Phone Fields

  • phone
  • mobile
  • work_phone
  • private_phone
  • emergency_phone

Supported Models

Contacts

Works with res.partner and res.company forms.

Employees

Supports HR employee phone validation fields.

Custom Models

Automatically works with custom models using supported field names.
