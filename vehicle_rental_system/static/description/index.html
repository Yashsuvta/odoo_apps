Vehicle Rental System

The Vehicle Rental System is a custom Odoo module that enables comprehensive management of vehicle rental operations. This module allows businesses to manage rental contracts, assign vehicles and drivers, track rental durations, invoice customers, and automate email notifications during the rental lifecycle. It is designed to streamline vehicle allocation, ensure proper contract handling, and integrate with Odoo native accounting and CRM systems.

Configuration

  • This module after installation adds the functionality of rental management See the Vehicle Rental as Main menu.

  • The vehicle Rental contains the dashboard which shows the Total Vehicle ,Vehicle Available ,Total Drivers ,Available in Graphical view.

Create Rentals

  • Now you can start creating rentals contract for your vehicles by clicking on the create button. It opens up a form view as above screen where the user will need to fill out the details about the Customer,Driver,Vehicle, Currency, Vehicle rent, Deposite, Contact details.

Manage Rental Contract

  • Clicking on the send contact buttons it send Contract to customer with all the necessary details.After sending waiting for the confirmation from the customer.

  • After confirmation from the user it move to confirmation state and the mail is drop to driver for regarding the booking and also the email to the customer regarding the driver information.

Drivers with Status

  • Click on the Drivers Menu after that all the drivers are visible with the different status like the Available and Engaged.

Customers

  • These all are the customer and you can also create the driver from the customers.

Vehicles With different Status

  • Contains all the vehicles with different State.

Create or Edit vehicle Information

  • By Clicking the new button you can create the new vehicle and also edit the exisitng the vehicle information.

Create or Edit Customer and Driver Information

  • By clicking the new button you can create the new customer and if the boolean field names as driver is check than it is driver not a customer and also status field for the driver status.
