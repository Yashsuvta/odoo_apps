=========================
Dynamic Field Manager
=========================

Dynamic Field Manager allows administrators and developers
to dynamically configure Odoo field properties directly
from the user interface without modifying Python code
or XML views.

=================================
Main Features
=================================

* Dynamically make fields readonly
* Dynamically make fields required
* Dynamically hide fields
* Enable or disable chatter tracking
* Runtime XML view modification
* Native Odoo tracking support
* Binary/Image field tracking
* Developer debug menu integration
* Upgrade-safe architecture

=================================
Supported Features
=================================

* Readonly Configuration
* Required Configuration
* Invisible Configuration
* Tracking Configuration
* Binary/Image Tracking
* Dynamic Runtime Updates
* Odoo Native Chatter Support

=================================
How It Works
=================================

This module dynamically modifies Odoo views
during runtime using ``get_view()`` inheritance.

It also extends Odoo tracking behavior
to support dynamic chatter logging.

Field configurations are managed directly
from the user interface.

=================================
Usage
=================================

1. Install the module
2. Enable Developer Mode
3. Open any form view
4. Open Debug Menu
5. Click "Dynamic Field Configuration"
6. Configure field behavior dynamically
