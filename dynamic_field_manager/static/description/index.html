Dynamic Field Manager

Dynamically configure Odoo fields directly from the UI without writing Python or XML code.

Why This Module?

In standard Odoo, field properties like Readonly, Required, Invisible, and Tracking are controlled from Python code and XML views.

This module allows administrators and developers to configure those properties dynamically from the Odoo interface in real time.

Main Features

Readonly Fields

Dynamically make fields readonly without editing XML views.

Required Fields

Configure mandatory fields dynamically from UI.

Invisible Fields

Hide fields dynamically without view inheritance.

Chatter Tracking

Enable or disable Odoo native tracking dynamically.

Advanced Capabilities

  • Runtime XML View Modification
  • Native Odoo Tracking Support
  • Binary/Image Field Tracking
  • Developer Debug Menu Integration
  • No Core File Modification Required
  • Upgrade Safe Architecture
  • Fast Dynamic Field Processing
  • Works with Existing Odoo Models
